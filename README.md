# LEIA ANTES

Vamos subir aguns arquivos necessário para o simulador funcionar no Wordpress. São 2 arquivos JavaScript:

- `script.js`:
  O arquivo principal, com toda lógica do simulador, a logica de recomendação.
- `validation.js`:
  O arquivo apenas de validação dos campos do formulário.

## Data

Dentro dessa pasta são os arquivos de dados para alimentar o simulador. Na raiz da pasta, tem 4 arquivos das perguntas:

- `colhedora.json`
- `distribuidor_esterco.json`
- `misturador_racao.json`
- `moedor.json`

Além disso, existe a pasta `recomendacoes`, como o nome diz, são os resultados do simulador. Elas também são divididas em 4 arquivos:
- `colhedora.json`
- `distribuidor_esterco.json`
- `misturador_racao.json`
- `moedor.json`



Precisamos de alguam froma simples de subir os arquivos e editar, de forma rápida e de fácil acesso.
